# SFTP and File Management Examples

Browse, download, and manage files on your Mac or any SSH server directly from ClawTerminal. Includes the Snap & Code workflow for turning photos into running code.

---

## 1. Browse files on a remote server

1. Connect to a server via SSH
2. Tap the **Files** tab (within My Mac, or via the Files sub-tab)
3. The SFTP browser opens at your home directory
4. Tap any folder to navigate into it — breadcrumbs at the top show your current path
5. Tap any file to preview it

**Navigate quickly:**
- Tap the breadcrumb labels to jump up the directory tree
- Tap a directory row to enter it

**What you can do from a file row (long-press for context menu):**
- Preview file contents
- Download to iPhone
- Delete (with confirmation)
- Rename

---

## 2. Download a single file

1. Navigate to the file in the SFTP browser
2. Long-press the file row
3. Tap **Download**

The file is saved to your iPhone's Files app (iCloud Drive or local storage). You can then open it in any iOS app that supports that file type.

**Common use cases:**
- Download a log file to read in a text editor
- Download a CSV to open in Numbers or Excel
- Download a PDF report generated by a background job
- Download an image or screenshot from your server

---

## 3. Batch select and download multiple files

When you need several files at once:

1. Tap the **Select** button in the breadcrumb bar
2. The browser enters multi-select mode — each row shows a circle on the left
3. Tap each file you want — the circle fills with a checkmark
4. Tap **Select All** (in the action bar at the bottom) to select everything in the current directory
5. Tap **Download** in the action bar

Progress is shown as files transfer. All selected files land in your Files app.

**Note:** Batch download works on files only, not folders. Select the files within a folder, not the folder itself.

---

## 4. Batch delete

Clean up old logs, temp files, or build artifacts:

1. Enter multi-select mode (tap Select in the breadcrumb bar)
2. Select the files and folders to delete
3. Tap **Delete** in the action bar
4. Confirm the deletion in the dialog

**Example: Delete all .log files in ~/logs/**
1. Navigate to `~/logs/`
2. Tap Select → Select All
3. Deselect any files you want to keep
4. Tap Delete → confirm

**Warning:** Deletions are permanent. There's no trash — files are removed from the server immediately.

---

## 5. Upload files from your iPhone

1. Navigate to the destination directory in the SFTP browser
2. Tap the **Upload** button (top right)
3. The iOS Files picker opens — select one or more files
4. The files upload to the current directory via SFTP

**Use case: Upload a config file you edited on iPhone**
1. Create or edit a file in iOS Notes or a text editor app
2. Export it to Files
3. Navigate to the config directory in ClawTerminal SFTP
4. Upload it directly

## 6. Snap & Code — photograph a mockup, get running code

This three-step workflow turns any visual into code running on your Mac:

**Step 1: Take a photo**

Option A — from an empty chatroom:
Tap the purple **"Snap & Code"** chip in the empty chat state.

Option B — from any message:
Tap the **attachment (paperclip)** button → **Take Photo**.

**Step 2: Describe what you want**

The input field pre-fills with:
```
Look at this image and generate code that recreates or addresses what you see.
```

Edit it to be more specific:
```
Look at this image. It's a wireframe of a signup form with email, password, confirm password, and a submit button. Generate a SwiftUI view that matches this layout.
```

**Step 3: Tap the Run button**

Claude's response includes a code block with a green **Run** button in the header. Tap Run — the code executes on your Mac via SSH. No copy-pasting required.

---

### Snap & Code — practical examples

**UI mockup → working HTML:**
1. Draw a card component on paper: title, subtitle, image, action button
2. Take photo via Snap & Code
3. Send with: "Generate this as a React component using Tailwind CSS"
4. Tap Run to open it in the browser on your Mac

**Error screen → diagnosis:**
1. See an error on your laptop screen or another device
2. Photograph it
3. Send with: "Explain this error and provide the fix"
4. Claude reads the error text from the image

**Whiteboard architecture → Mermaid diagram:**
1. After a design meeting, photograph the whiteboard
2. Send with: "Convert this whiteboard sketch to a Mermaid flowchart"
3. Claude produces diagram markup you can paste into documentation

**Handwritten SQL schema → working migration:**
1. Sketch table relationships on paper
2. Photograph and send: "Generate SQLAlchemy models and an Alembic migration from this schema"
3. Tap Run to apply the migration

## 7. AI error diagnosis — the "Ask Claude" pill

When the terminal output matches an error pattern, a floating **"Ask Claude"** pill appears automatically at the bottom of the terminal screen.

Tap it to switch to Claude's chatroom with a pre-filled diagnosis prompt:

```
I see this error in my terminal:

<last 30 lines of terminal output>

What caused this and how do I fix it?
```

**Recognized patterns include:**
- `command not found`
- `Permission denied`
- `SyntaxError:` / `TypeError:` / `NameError:`
- `npm ERR!` / `pip error` / `yarn error`
- `ENOENT` / `EACCES`
- `Connection refused` / `No such file or directory`

The pill auto-dismisses after 10 seconds if you don't tap it.
